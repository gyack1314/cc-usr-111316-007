# 多名单捕获分析（capture_analysis）

在人工核验稳定家庭 ID 的前提下，对 3–6 个渠道的捕获历史做分层 Poisson 对数线性
捕获-再捕获分析，估计从未出现在任何渠道的家庭数（全零格均值 λ₀）与总人数，
并把假设无法验证的部分显式列出。纯 Python 标准库实现，无第三方依赖。

## 与只读模块的关系

- `analysis_data/` 只负责读取冻结 JSON、核验资产身份与基本形状，不产生任何估计。
- `capture_analysis/` 是独立分析包，通过 `pipeline.load_manifest` 复用只读加载器，
  不修改原始数据，也不向读取模块回写任何分析逻辑。

## 运行（隔离模式 python -I）

```sh
# 完整分析，Markdown 报告
python -I run_capture.py analyze data/normal.json
# 严格 JSON（无穷上界序列化为 null，配套 upper_infinite 布尔标志）
python -I run_capture.py analyze data/normal.json --format json -o result.json
# 只输出可回溯捕获历史表与对账
python -I run_capture.py history data/normal.json
# 测试
python -I run_tests.py
```

## 统计口径与方法

### 1. 捕获历史表

- 每家庭带全渠道出现位图与登记分层；至少一位为 1，全零行被拒绝。
- 重复家庭按位 **OR** 合并；同一家庭分层不一致即 `StratumConflictError` 阻断。
- 枚举全部 2^k 个格子：观测格给计数，未观测但可能的格子显式记 0，
  结构零（全分层统一）单列且不进入设计矩阵、不参与似然与预测。
- 全零格 000 是否可能单独标注；若 000 是结构零，未观测数固定为 0，不外推。
- 结构零格中出现观测即判输入矛盾。

### 2. 设计矩阵与可识别性

- 模型项 = 截距 + 清单声明的交互项；强制层级原则（缺低阶项直接报错）。
- 同时报告精确秩（Fraction 高斯消元）与数值秩（列主元 QR）。
- 设计秩 < 参数数（如结构零减格后的饱和模型）判 `design_rank_deficient`，不拟合、
  不产生人数，不靠默认正则编造估计。

### 3. 有限 MLE 存在性（Haberman 判据）

对零计数格的设计行求解可行性 LP：是否存在 β 使每个零格 `Xβ ≥ 1`。
LP 用精确 `Fraction` 两阶段单纯形（Bland 反循环规则）实现，
并对返回见证逐行复核。无解则有限 MLE 不存在（`mle_infinite`），
系数向边界发散，单独报告；与优化器数值未收敛（`optimization_failed`）严格区分。

> 说明：当 000 是可能格时，其设计行是纯截距 [1,0,…]，该 LP 恒可行。
> 此时饱和模型仍可能把 λ₀ 推到边界（点估计≈0、轮廓上界无穷），
> 这是“有限边界 MLE 但 λ₀ 不可识别”，由轮廓区间与可识别性标志体现，
> 而非 LP 不可行。LP 不可行分支作为防御性代码保留并单测。

### 4. 拟合与诊断

- Poisson 对数线性用阻尼 IRLS（回溯线搜索保证对数似然单调），
  紧约束/病态时回退到带回溯的 BFGS；零计数绝不加 0.5。
- 完整 Poisson 似然含 `log(y!)` 阶乘常数。
- 信息矩阵报告 Jacobi 特征值、最小特征值与条件数，近奇异显式标注。

### 5. λ₀ 轮廓似然区间与总人数

- 约束 `c'β = log(λ₀)`（c 为全零格设计行）下重拟合，
  阈值 `2(ℓ_max − ℓ_profile) = χ²₁(α)`，α 取自清单 `profile_confidence`。
- 在 log 空间自适应单调性二分；上确界仍不越阈则上界记 **无穷并保留**。
- 总人数 = 观测并集 n + λ₀；多分层各自拟合，跨层给点估计之和与
  保守包络区间（明确不是联合似然区间）。
- λ₀ 可识别性：区间有限且下界 > 0 才可识别；触及 0 或上界无穷即不可识别，
  其点估计只是边界极限。

### 6. 模型比较与平均

- 同一观测格似然；AICc 的 k 为可识别自由参数，n 为该层观测家庭数；
  `n ≤ k+1` 时 AICc 不定义（输出 null 与原因）。
- 模型平均**只平均点估计**，按 AICc 权重，且仅纳入可估且 λ₀ 可识别的模型；
  绝不把各模型区间端点加权后称为有效区间。

### 7. 两条预登记敏感性路径

- **路径 A（未观测格）**：向每个未观测但可能的格子逐个注入预设小整数计数后重拟合，
  注入是假设情景，不改原始计数、不加 0.5。
- **路径 B（最高阶依赖）**：把完整 k 渠道交互系数固定为清单预设值，其余重拟合；
  原模型缺该项时按层级原则临时补入，固定 0 即隐含的渠道独立性。
  渠道独立性**无法从无名单家庭验证**，该声明随结果固定输出。

## 输出状态码

| 状态 | 含义 |
| --- | --- |
| `ok` | 有限 MLE，优化收敛，信息矩阵非奇异 |
| `design_rank_deficient` | 设计秩 < 参数数，不可识别，不产生人数 |
| `mle_infinite` | Haberman LP 无解，MLE 在边界发散 |
| `optimization_failed` | LP 可行但数值优化未收敛（与上者分别报告） |

## 测试

`tests/test_capture.py`（40 用例）覆盖四个指定场景——全独立、强渠道依赖、
单一稀疏格、已知结构零——以及历史表合并/冲突、设计秩、单纯形 LP、
信息矩阵特征值、AICc 规则、轮廓根精度、可识别性排除、多分层、
敏感性路径与端到端清单对账。`tests/reference.py` 提供独立闭式/牛顿参照。
